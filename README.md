# ⚡ 포켓몬 챔피언스(포챔스) AI 자동 편집 & 유튜브 업로드 파이프라인
> **유명 유튜버 '테디님' 스타일의 100% 전자동 영상 편집 및 유튜브 업로드 시스템**

사용자가 포켓몬 챔피언스 20분짜리 게임 녹화본(`.mp4`)을 넣기만 하면, **승리 경기 감지 → 지루한 턴 대기 시간 4배속 압축 → 결정타 순간 1배속 복귀 + 1.2배 줌인 → 고화질 어그로 썸네일 생성 → Gemini SEO 최적화 메타데이터 생성 → 유튜브 '일부공개(unlisted)' 업로드**까지 전 과정을 전자동으로 수행합니다.

---

## 📌 주요 기능 (Pipeline Highlights)

1. **OpenCV 템플릿 매칭 승리 경기 감지 (`detector.py`)**
   - 게임 결과창에 '승리(WIN)'가 뜬 경기만 감지하여 패배 경기는 자동으로 제외합니다.
   - 다중 스케일 매칭을 지원하여 해상도 차이가 있어도 정확하게 승리 시점을 포착합니다.
   - 각 승리 경기의 [시작 ~ 배틀 ~ 결정타(승리 직전 5초) ~ 종료] 구간을 정밀 분할합니다.

2. **테디님 특유의 템포 편집 (`editor.py` - auto-editor + MoviePy)**
   - `auto-editor`를 활용해 볼륨 4% 이하 구간(턴 고민/대기 시간)을 **4배속(4x)**으로 빠르게 압축합니다.
   - 각 경기의 마지막 결정타 순간은 다시 **1.0배속(정상 속도)**으로 복귀시키고, **화면 중앙을 1.2배 줌인(Zoom-in)**하여 타격감과 몰입감을 극대화합니다.
   - 모든 승리 경기 하이라이트를 자연스럽게 이어붙여 최종 영상(`final_video.mp4`)으로 렌더링합니다.

3. **Pillow 어그로 썸네일 자동 생성 (`thumbnail.py`)**
   - 결정타 순간의 가장 극적인 프레임을 캡처하고 채도 및 대비를 부스팅합니다.
   - **맑은 고딕 볼드(malgunbd.ttf)** 폰트로 텍스트를 자동 합성합니다.
     - **상단 서브 텍스트**: 흰색 글씨 + 두꺼운 검은색 테두리 (Stroke)
     - **중앙 메인 텍스트**: 테디님 시그니처 형광 노란색(`#FFE812`) + 매우 두꺼운 검은색 테두리
     - **포챔스 뱃지**: 좌측 상단 강렬한 레드 뱃지 포함
   - 유튜브 표준 규격인 1280x720 해상도의 `final_thumbnail.jpg`로 저장합니다.

4. **Gemini API 기반 SEO 메타데이터 생성 (`metadata_generator.py`)**
   - Gemini 모델을 호출하여 테디님 특유의 텐션 높은 어그로 제목, 호기심 유발 설명문(경기별 타임라인 포함), 검색 최적화(SEO) 해시태그 15개를 JSON 포맷으로 자동 생성합니다.

5. **유튜브 자동 업로드 (`uploader.py` - YouTube Data API v3)**
   - 최종 렌더링된 영상, 썸네일, 제목/설명/태그를 바탕으로 채널에 **일부공개(unlisted)** 상태로 즉시 업로드합니다.
   - OAuth 2.0 토큰을 로컬에 안전하게 캐싱하여 최초 1회 브라우저 로그인 후 영구 자동화됩니다.

```
├── main.py                    # 파이프라인 전체 실행 오케스트레이터

├── .env                       # (사용자 준비) GEMINI_API_KEY 설정 파일

    ├── final_video.mp4        # 완성된 하이라이트 영상
    ├── final_thumbnail.jpg    # 생성된 썸네일 이미지
    └── metadata.json          # 유튜브 메타데이터 (제목, 설명, 태그)
```

## 🚀 빠른 시작 가이드 (How to Run)

### 방법 1: 바탕화면에서 드래그 앤 드롭 (가장 쉬운 방법)
1. 편집하고 싶은 게임 녹화본(`.mp4`) 파일을 마우스로 잡습니다.
2. `run.bat` 파일 위로 **드래그 앤 드롭**하여 놓습니다.
3. 자동으로 명령창이 열리며 1단계부터 5단계까지 순차적으로 진행됩니다.

### 방법 2: 명령줄(CLI) 실행
```bash
# 기본 실행 (편집부터 유튜브 업로드까지)
python main.py "C:\경로\포챔스_녹화본.mp4"

# 유튜브 업로드 없이 로컬 영상/썸네일/메타데이터만 생성할 때
python main.py "C:\경로\포챔스_녹화본.mp4" --skip-upload

# 템플릿 매칭 임계값 조정 (기본값: 0.70)
python main.py "C:\경로\포챔스_녹화본.mp4" --threshold 0.65
```

## 🔑 필수 API 키 및 인증 파일 발급 가이드

### 1. Gemini API 키 발급 및 설정 방법 (무료)

1. **[Google AI Studio](https://aistudio.google.com/)** 사이트에 접속하여 구글 계정으로 로그인합니다.
2. 좌측 상단의 **"Get API key"** 버튼을 클릭합니다.
3. **"Create API key"**를 클릭하여 새로운 키를 생성하고 복사합니다.
4. 아래 두 가지 방법 중 편한 방법으로 키를 등록하세요:
   - **방법 A (.env 파일 생성 - 권장)**:
     프로젝트 폴더 안에 `.env` 파일을 만들고 아래 내용을 적습니다:
     ```env
     GEMINI_API_KEY=your_actual_gemini_api_key_here
     ```
   - **방법 B (윈도우 환경변수 등록)**:
     명령 프롬프트(CMD) 또는 PowerShell에서 실행:
     ```cmd
     setx GEMINI_API_KEY "your_actual_gemini_api_key_here"
     ```
> 💡 *참고*: API 키를 아직 설정하지 않은 상태에서 실행하더라도, 시스템은 멈추지 않고 내장된 테디님 스타일 프리셋 메타데이터를 사용하여 정상 작동합니다.

---

### 2. YouTube Data API v3 인증 파일 (`client_secrets.json`) 설정 방법

유튜브 채널에 자동으로 영상을 업로드하기 위해 구글 클라우드에서 OAuth 2.0 클라이언트 키를 받아야 합니다.

1. **[Google Cloud Console](https://console.cloud.google.com/)**에 접속합니다.
2. 상단 프로젝트 선택 드롭다운을 눌러 **새 프로젝트(New Project)**를 만듭니다 (예: `Pokemon-Auto-Editor`).
3. 좌측 메뉴에서 **[API 및 서비스] → [라이브러리]**로 이동합니다.
4. **"YouTube Data API v3"**를 검색한 뒤 클릭하고 **[사용(Enable)]** 버튼을 누릅니다.
5. 좌측 메뉴에서 **[OAuth 동의 화면(OAuth consent screen)]**으로 이동합니다:
   - 사용자 유형(User Type): **외부(External)** 선택 후 만들기
   - 앱 이름(예: `Pokemon Uploader`), 사용자 지원 이메일, 개발자 연락처 이메일을 입력하고 저장합니다.
   - **[테스트 사용자(Test users)]** 탭에서 영상을 올릴 본인의 유튜브 구글 계정을 추가합니다. (중요!)
6. 좌측 메뉴에서 **[사용자 인증 정보(Credentials)]**로 이동합니다:
   - 상단의 **[+ 사용자 인증 정보 만들기] → [OAuth 클라이언트 ID]** 클릭
   - 애플리케이션 유형: **데스크톱 앱(Desktop App)** 선택
   - 이름 입력 후 **[만들기]** 클릭
7. 생성된 OAuth 클라이언트 우측의 **다운로드(JSON 다운로드) 아이콘**을 클릭합니다.
8. 다운로드된 파일의 이름을 **`client_secrets.json`**으로 변경한 뒤, 이 프로젝트 루트 폴더에 복사해 넣습니다.
9. **최초 실행 시**:
   - `python main.py`를 실행하면 웹 브라우저가 열리며 구글 로그인 화면이 뜹니다.
   - 테스트 사용자로 등록한 유튜브 계정으로 로그인 후 접근 권한을 승인합니다.
   - 인증이 완료되면 `token.pickle` 파일이 자동 생성되어 다음 실행부터는 로그인 창 없이 100% 자동으로 업로드됩니다.

> 💡 *참고*: `client_secrets.json` 파일이 없어도 파이프라인은 오류로 멈추지 않으며, 최종 영상, 썸네일, 메타데이터 생성을 모두 완료한 뒤 유튜브 업로드 단계만 안전하게 스킵합니다.

## ⚙️ 커스텀 설정 변경 (`config.py`)

상황에 맞게 파라미터를 손쉽게 튜닝할 수 있습니다:
- `AUDIO_THRESHOLD = "4%"`: auto-editor 무음 감지 기준 (대화나 배경음악 크기에 맞춰 조절)
- `SILENT_SPEED = 4`: 고민/대기 시간 배속 (기본 4배속)
- `FINISHING_BLOW_DURATION = 5.0`: 결정타 줌인 구간 길이 (승리 직전 5초)
- `ZOOM_FACTOR = 1.2`: 결정타 화면 중앙 줌인 확대 배율
- `TEMPLATE_MATCH_THRESHOLD = 0.70`: 승리 화면 템플릿 매칭 감도
